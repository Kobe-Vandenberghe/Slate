# 2026-09-30 — ArchDoc v1: canonical board model

## Goal
Define Slate's canonical, JSON-based model language (ArchDoc v1) and plan its staged implementation.
It must be the source of truth for the board, carry optional architecture meaning, round-trip losslessly
with the canvas, be sliceable for AI, and act as the interchange layer for Mermaid, files, etc.

## Plan / tasks
- [x] Stage 0: brainstorm (domain storytelling), external review, spec `docs/archdoc.md`, ADR 0009.
- [ ] Stage 1: `archdoc` feature slice (pure, no UI change): types, validation, canonical serializer
      (key order, defaults omitted, 2-decimal rounding), parser. Full unit tests, including round-trip.
- [ ] Stage 2: switch the document store to ArchDoc. This is the biggest stage and may split into 2a/2b.
  - 2a: `Shape` → `Element`, `kind` → `shape`, rotation to degrees, `fill`/`stroke` → style tokens.
  - 2b: connectors become `connections`; derived connection geometry replaces the `syncConnectors` write-back;
        undo snapshots the whole doc; board title moves into the doc.
  - Storage schema v4 + v3 → v4 migration (skill `change-persisted-schema`).
  - Connections render above elements.
- [ ] Stage 3: meaning UI: set/clear `kind` ("make it a service"), properties panel with autocomplete, alias,
      connection label + properties.
- [ ] Stage 4: frames: create, explicit membership on drop, relative coordinates, move with children,
      release on delete + "delete with contents".
- [ ] Stage 5: `.slate.json` import/export.
- [ ] Stage 6: projections: selection/frame slicing with stubs, compact AI projection, temporary handles.
      Pure functions + tests only; no AI integration.

## Decisions
See `docs/archdoc.md`. Key points:
- Separate connections list, not nested under elements; the AI projection nests them under the source.
- Use `kind`, not `type`.
- No `null` property values.
- Waypoints are in board coordinates.
- Array order = sibling z-order, with no global frame-first rule.
- Strict JSON, no comments.
- Frames have no nesting or rotation, and their children use relative coordinates.
- Aliases are slugs, and ids are opaque.

## Roadblocks & edge cases
- In the current code `kind` means geometry. It must be renamed everywhere to `shape` in stage 2a, never half-done.
- Sticky and shape palettes share names with different colors, so token resolution depends on `shape`.
- Connectors are currently interleaved in z-order with shapes; after stage 2b they always draw on top.
- Existing boards may contain hex colors not in the palette. The migration needs a fallback token.
